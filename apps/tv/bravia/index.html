1132 FIXER

A focused browser cleanup for Zoom error 1132.

BROWSER EXTENSION NOT AVAILABLE ON THIS TV

This TV runs television software, not a desktop browser, so the 1132 Fixer browser extension cannot run here. Pick what fits your setup. Use the arrow keys to move and OK to open.

On a computer

  1. Open a zoom.us or zoom.com page in your browser.
  2. Install 1132 Fixer from your browser's extension store, or load the package from the project page.
  3. Open the extension and press FIX ZOOM. It clears Zoom cookies and that tab's Zoom site data, then reloads.

Project page: github.com/1132-Fixer/chrome

Website: 1132-fixer.xyz

Windows app

  1. On the Windows PC that shows Error 1132, open the project's Windows release page.
  2. Download and run the 1132 Fixer Windows app. It opens Zoom Workplace under a fresh local helper account.

Releases: github.com/1132-Fixer/windows/releases/latest

Zoom app on this TV

This guide cannot clear another app's data for you. TV software keeps each app's data private. The steps below are the general Android TV / Google TV path; the exact menu names depend on your model and software version.

  1. Press HOME on the remote, then open Settings.
  2. Open Apps, then See all apps, and choose the Zoom app.
  3. Choose Clear cache, then Clear data (also called Clear storage).
  4. Open Zoom again and sign in.

If Error 1132 continues, the cause is not this TV's Zoom data. Use Option 1 or Option 2 on a computer.
