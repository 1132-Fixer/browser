# Primary-source research record

Every material architectural decision in this workspace traces to an official vendor page. Each row
records the exact page, the date it was read, the platform and version it applies to, the constraint
or opportunity it establishes, the effect on the implementation, the decision made, and anything
still uncertain. Search-result pages are never cited. Pages were fetched on 2026-09-10 and saved as
text for the record; re-verify before relying on a row after a platform release.

## Chrome (Chromium)

| Source | Verified | Applies to | Constraint / opportunity | Effect | Decision | Uncertainty |
|---|---|---|---|---|---|---|
| [Manifest file format](https://developer.chrome.com/docs/extensions/reference/manifest) | 2026-09-10 | Chrome, MV3 | Required keys are `manifest_version`, `name`, `version`; the Web Store also requires `description` (132 chars max) and `icons`. `host_permissions` are requested at install. | Base manifest carries all five; `verify:manifests` enforces the 132-char limit. | Chrome manifest is the base every other target composes from. | None. |
| [Content security policy](https://developer.chrome.com/docs/extensions/reference/manifest/content-security-policy) | 2026-09-10 | Chrome, MV3 | Default `extension_pages` policy is `script-src 'self'; object-src 'self';`; it cannot be relaxed beyond `'self' 'wasm-unsafe-eval'`. No inline script, no `eval`. | Bundles are plain local scripts; pages carry no inline script or handlers. | Declare the default policy explicitly so reviewers and `verify:manifests` can read it. | None. |
| [Remotely hosted code](https://developer.chrome.com/docs/extensions/develop/migrate/remote-hosted-code) | 2026-09-10 | Chrome, MV3 | "RHC is not allowed": all logic must ship in the package. | Everything is bundled by esbuild from local sources; `lint` and `verify:packages` scan for `fetch`, `eval`, `new Function`, external script tags. | No remote code, no remote configuration. | None. |
| [The activeTab permission](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab) | 2026-09-10 | Chrome | Executing the action grants temporary host access to the current tab: `scripting.executeScript`, tab URL, until navigation. No install warning. | Popup reads the tab URL and injects into the active tab only after the user's click. | Keep `activeTab` + `scripting`; never `tabs`. | None. |
| [chrome.scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting) | 2026-09-10 | Chrome 90+ (`func` Chrome 92+) | `executeScript` with `func` serializes the function; arguments must be JSON-serializable; needs `scripting` plus host permission or `activeTab`. | The cleaner is a self-contained function; a unit test runs its source text in a bare `vm` context to prove it closes over nothing. | One injection site, in the adapter. | None. |
| [chrome.cookies](https://developer.chrome.com/docs/extensions/reference/api/cookies) | 2026-09-10 | Chrome 119+ for `partitionKey` | `getAll` only returns cookies for hosts with host permission; `partitionKey` (Chrome 119+) selects partitions. | `collectCookies` queries with an empty `partitionKey` first and falls back to the plain query on browsers that reject it. | Keep `minimum_chrome_version` at 114 (unchanged); the fallback covers 114 to 118. | None. |
| [minimum_chrome_version](https://developer.chrome.com/docs/extensions/reference/manifest/minimum-chrome-version) | 2026-09-10 | Chrome | Raising it silently stops updates for older users. | Left at 114. | Do not raise without a product decision. | None. |

| [IDBFactory.databases()](https://developer.mozilla.org/en-US/docs/Web/API/IDBFactory/databases) | 2026-09-10 | Firefox 126+ (Baseline May 2024) | Not available before Firefox 126. | Covered by the 140 minimum; a missing API is still reported as an IndexedDB error, never as success (unit test). | Minimum Firefox is 140 (ADR 0007). | None. |
| [Signing and distribution overview](https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/) | 2026-09-10 | Firefox | Release and Beta only install signed packages; signing is through AMO, listed or unlisted; `web-ext sign` handles both. | [Source code submission](https://extensionworkshop.com/documentation/publish/source-code-submission/) | 2026-09-10 | AMO review | Bundled or transpiled code requires source and build instructions: OS, Node version, exact commands, reproducible output. | [web-ext command reference](https://extensionworkshop.com/documentation/develop/web-ext-command-reference/) | 2026-09-10 | Tooling | `web-ext lint` validates the manifest against the `strict_min_version`. | `verify:manifests` runs it on `dist/firefox` with JSON output and fails on errors. | Pinned devDependency. | Exactly one warning remains, re-measured 2026-09-11 on `dist/firefox`: 0 errors, 1 warning, 0 notices. The earlier note here said two warnings about Firefox 128; that was true before `strict_min_version` moved to 140 (ADR 0007). |
